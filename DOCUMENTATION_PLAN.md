# Auctrail customer documentation plan

> The customer Knowledge Base now lives at https://support.auctrail.com/hc/2528629480. The pages under `docs-site/` forward existing links there; publish new customer guides in FreeScout rather than expanding this retired static-site outline.

## Writing standard

- Write for a first-time user with no technical background.
- Use one task per guide and short numbered steps.
- Use the exact button and page names shown in Auctrail.
- Place a current, privacy-safe screenshot beside the steps it explains.
- Explain unavoidable terms the first time they appear.
- State what the user should see after completing the task.
- End task guides with a short “If this happens” help section.
- Mark each guide as Web application, iPad application, or Both.
- Replace screenshots whenever the related screen changes.
